# Day 12 Task – Responsive Pricing Table

## Project Overview
The Responsive Pricing Table is a modern and user-friendly web design project developed using HTML and CSS. It features three pricing plans: Basic, Pro, and Premium, with attractive card layouts, smooth hover effects, and a responsive design.

The project is designed to provide a clean and engaging user experience across desktop, tablet, and mobile devices.

## Features
- Three pricing cards: Basic, Pro, and Premium.
- Attractive and modern UI design.
- Different color themes for each pricing plan.
- Hover effects on pricing cards.
- Dynamic box shadow on hover.
- Border color change when hovering over cards.
- Smooth button hover animations.
- Responsive layout for mobile, tablet, and desktop.
- Flexbox for proper alignment and spacing.
- CSS media queries for responsive design.

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Media Queries
- CSS Transitions

## Responsive Design
- Desktop: Three pricing cards displayed in a single row.
- Tablet: Cards adjust their width according to screen size.
- Mobile: Cards are displayed vertically for better readability.
