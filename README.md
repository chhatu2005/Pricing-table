# Day 12 Task – Responsive Pricing Table

## Project Overview

A simple and responsive pricing table created using HTML and CSS. It includes three pricing plans: Basic, Pro, and Premium, with attractive designs and hover effects.

## Features

* Three pricing cards.
* Attractive UI design.
* Hover effects with box shadow.
* Border color change on hover.
* Smooth transitions.
* Responsive layout for mobile and desktop.

## Technologies Used

* HTML5
* CSS3
* Flexbox
* Media Queries

## Project Structure

```text
Day 12 Task/
├── index.html
├── style.css
└── README.md
```

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Run `index.html` in your browser.
